# Lista de Tareas (Proyecto 1)

## Cómo correr el proyecto:

1. Abre la terminal en esta carpeta y escribe el comando `npx tsc` (esto prepara el código).
2. Ve a tus archivos, haz clic derecho sobre `index.html` y selecciona **"Open with Live Server"**.
3. ¡Listo! La aplicación se abrirá sola en tu navegador.
